# 实机验证

这些检查需要 Windows x64、扩展副屏和可操作的图形桌面。先构建 `release\副屏助手.exe`，退出正在运行的副屏助手，保存工作并切回桌面，再运行：

```powershell
& .\verify.ps1
```

此脚本编译检查程序；默认不启动图形测试。需要实际验证时使用：

```powershell
& .\verify.ps1 -Run
```

`-Run` 会生成临时测试窗口、图片、托盘图标和验证截图，发送 Alt+Tab、鼠标及 Esc，并移动或关闭测试窗口。不要在游戏抓取输入、锁屏或无桌面环境下运行。不要将生成的 `data`、日志和截图上传仓库。

- `Verify`：同名窗口点击和正常关闭、托盘菜单、原生右键回调、外部点击及 Esc、混合缩放和任务栏显隐。
- `FeatureCheck`：图片质量、缓存、透明通道、控制面板布局、直接移屏及取消逻辑。
- `WindowCompatibility`：无标题与所属对话框预览、枚举过滤和实际点击。
- `SettingsCheck`：加载正式构建的程序集，检查设置页与应用按钮保存。
- `TrayPopupCheck`：自建原生应用菜单在两个副屏的准确 HWND、边界、关闭，以及普通窗口不被误移动；不向用户应用发送鼠标或键盘输入。
- `KeyboardCheck`：左右 Win 手势、组合键与修饰键排除、重复按下和多次创建/关闭输入线程；主线程阻塞时探测真实键盘监听消息循环，完全不生成键盘输入。
- `ResponseCheck`：旧配置兼容与开关保存、响应策略、LRU 缓存限额及文件/清晰度失效、像素缓冲复用与透明输出一致、大字体设置布局、同一 HWND 的 DWM 缩略图复用、鼠标线程在主线程阻塞时仍响应。只操作自身的界面和测试窗口，不注入全局按键或鼠标点击；打印的帧耗时属于本机单一合成图像测量。
- `WallpaperCheck`：复杂清晰/带色壁纸的背景分离与深浅色图标保留，不匹配背景回退、壁纸显示方式及负坐标、旧配置与开关保存、系统实际多屏壁纸读取、自动隐藏透明帧的背景匹配和裁剪上限。只使用自身图片/窗口及只读壁纸 API，不更改系统壁纸或注入鼠标键盘；合成结果不能代替真实 TranslucentTB 电脑验收。
- `TrayPointerCheck`：同批输入的点击/归还顺序、自动隐藏超时、界面阻塞期间独立恢复、真实输入撤销、坐标取整、可见性/cloak/四边隐藏区域、内容桥显隐和隐藏启动生命周期；采用模拟输入后端及自身原生窗口，不注入全局输入。
- `SwitcherSelectionCheck`：五个同标题 HWND、不同列宽首行末项、DWM 源绑定、鼠标按下快照与重排、Alt 松开和点击竞争、过期请求取消；默认只记录提交的 HWND。可选 `--native` 打开正常图形按钮，点击后检验自身窗口实际前台激活，不注入全局按键或鼠标。
- `DesktopStartupCheck`：阻塞假 Explorer 读取时界面仍能处理计时器，串行请求合并，以及关闭、代次和屏幕变化后拒绝迟到结果；不读取真实 Explorer 或安装全局监听。
- `StartMenuCheck`：真实 DWM 句柄、焦点保留、混合分辨率位置、隐藏和 cloak 后还原、异步监听就绪/释放、鼠标配对/拖动/过期快照取消及原生任务栏不被移动；仅使用自身窗口和模拟输入序列，不注入全局输入。
- `LatencyCheck`：固定图像的完整输出字节与 v1.1.4 基线比较、缓存限额和错误清理；本机 100 帧中位数与 p95，只测透明背景处理，不代表端到端点击响应。

编译使用与正式版本相同的 PerMonitorV2 manifest 和优化选项；自行编译时遗漏 DPI manifest，可能导致壁纸接口的物理坐标与测试窗口坐标不匹配。

脚本不修改系统启动项或任务栏设置。测试会短暂改变前台窗口和鼠标位置，可能干扰正在进行的操作；生成内容保存在验证目录中。
