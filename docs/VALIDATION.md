## v1.1.0

v1.1.0 的实际交互回归于 2026-10-09 在 Windows 三屏环境完成；主屏 100% 缩放，右侧目标副屏 1920×1080、150% 缩放，另有负坐标左侧屏幕。

通过的检查：

- 真实 Alt+Tab 显示副屏面板，同时保留主屏原生切换器。
- 两个同名测试窗口分别绑定 HWND、DWM 预览、点击和正常关闭；只关闭指定窗口。
- 无标题窗口、所属对话框、隐藏宿主对话框识别及实际预览与点击。
- 鼠标选中和松开 Alt 后移动原生实际选中的窗口；关闭选项时只切换；Esc 取消时不移动。
- 普通、最大化、最小化窗口及负坐标副屏移动；最大化状态保留。
- 三档实际图片缩略图、边长限制、宽高比例和后台缓存刷新。
- 透明背景通道、深浅色图标保留；实际截图核对副屏原生时钟没有镜像时钟叠加。
- 控制面板不同缩放和较大字体下行间无重叠，应用按钮保存便携配置。
- 托盘物理像素对齐、展开及自动隐藏；完整原生菜单、真实图标右键、Esc、再次点击和外部点击收起。
- 界面阻塞 1.3 秒期间仍收到外部点击，恢复后收起托盘菜单。

最后一次完整回归中托盘菜单展开为 125 毫秒，不是其他电脑的性能保证。
