# ScreenCompanion · 副屏助手

Windows 多屏便携工具：把桌面文件图标、可点击的 Alt+Tab 窗口面板和系统托盘放到指定副屏。

Portable Windows utility for desktop file icons, live window previews and an interactive system tray on a secondary monitor.

## 下载和使用

从 [Releases](https://github.com/sanmajiao/ScreenCompanion/releases) 下载 `ScreenCompanion-v1.1.2-win-x64.zip`，解压到可写目录，双击 `副屏助手.exe`。无需 Python、Node、.NET SDK 或账号。

GitHub 自动生成的 “Source code” 压缩包是源码；运行程序请下载上面的便携 ZIP。

1. Windows 使用扩展桌面，在设置中选择目标副屏。
2. 勾选所需功能，点击「应用设置」。关闭设置窗口会收起到系统托盘。
3. 双击程序或副屏托盘齿轮可重新打开设置；退出请使用设置或托盘菜单中的「退出」。

支持 Windows 10 / 11 x64 和 .NET Framework 4.x。仅一块屏幕时暂停副屏功能，连接后自动恢复。

## 功能

- **桌面文件图标克隆**：显示用户桌面和公共桌面的文件、目录、快捷方式，不复制文件内容。双击打开原文件，拖动图标保存布局；保留副屏已有的原生桌面图标。不是整屏画面或壁纸镜像。
- **实时窗口面板**：按住 Alt 并按 Tab，副屏显示 DWM 实时预览。标题、缩略图、点击和正常关闭绑定同一窗口，支持无标题窗口和所属对话框；滚轮翻页。主屏原生 Alt+Tab 保留。
- **选中后直接移屏**：勾选「切换时将选中的窗口直接移到目标副屏」。点击卡片或 Alt+Tab 后松开 Alt，实际选中的窗口会移到副屏，保留最大化状态；Esc 取消时不移动。默认关闭。
- **副屏开始菜单**：单独按 Win（或 Ctrl＋Esc），将 Windows 原生开始菜单定位到目标副屏，并临时显示该屏原生任务栏；菜单关闭后恢复任务栏原有位置。Win＋E、Win＋D 等组合键继续交给系统。此功能已在本机 Windows 11 验证菜单路径，Windows 10 的开始菜单宿主尚未验收。
- **交互式托盘**：主屏托盘图标映射到副屏，跟随副屏原生任务栏显示和隐藏；支持左右键及双击。箭头在副屏展开完整的原生隐藏图标菜单，图标可直接操作；箭头再次点击、外部点击或 Esc 可收起。
- **透明背景**：默认去除截图背景，叠加到副屏任务栏；复用副屏原生时钟，避免重影。可关闭透明恢复原始镜像。
- **图标与图片清晰度**：低 32、中 64、高 128 像素，默认中；图片显示实际缩略图，后台加载。每 100 张正方形图像缓存约为 0.4 / 1.6 / 6.3 MiB，问号说明缓存与总内存的区别。

配置和布局保存在程序旁的 `data`，目录只读时回退到当前用户本地应用数据目录 `ScreenCompanion`。分享给其他人时不要携带个人 `data`。

## 使用边界

- 托盘需要 Windows 开启「在所有显示器上显示任务栏」。音量、网络等系统弹窗及应用托盘菜单会定位到目标副屏；弹窗由 Windows 或应用提供。透明模式下时钟使用原生副屏时钟，日历仍走原生点击路径。
- 主屏任务栏隐藏时图标使用最近一次捕获；首次读取和点击会短暂展开主屏任务栏并恢复鼠标。透明模式下副屏原生时钟正常更新。
- Win11 托盘截图已经混入壁纸。透明通道使用背景分离估算，复杂背景或特殊图标可能残留边缘，可以关闭透明模式。
- 副屏窗口面板使用独立窗口列表，浏览器标签、应用分组与 Windows 特殊窗口的排列、高亮可能与原生 Alt+Tab 不同；键盘移屏跟随原生实际选中的窗口。
- 管理员应用可能需要副屏助手以相同权限运行。程序未做商业代码签名。
- 本机三屏和混合缩放已验证；其他电脑、ARM64、第三方任务栏、远程桌面和特殊主题尚未全面验证。不支持 macOS、Linux 或 Windows 32 位。

## 从源码构建

在 Windows x64 上打开 PowerShell，在源码目录运行：

```powershell
& .\build.ps1
```

使用系统自带的 .NET Framework 编译器，输出 `release\副屏助手.exe`；无需下载依赖。打包运行：

```powershell
& .\package.ps1
```

输出便携 ZIP 和校验文件到 `dist`。可重复执行构建，但未承诺不同环境下二进制哈希完全相同。
